做市策略拆解（基于公开信息）

1. 反延迟军备竞赛：「拼大脑，不拼神经末梢」

  • Gerko 明确不参与跨大西洋直连光纤 / 交易所旁微波塔等「微秒军备竞赛」，甚至公开游说监管引入「减速带」（speed bumps）抑制超高频交易。
  • 竞争焦点放在短周期价格预测精度：深度模型对未来数秒至数小时的价格路径给出高置信度判断，在受限延迟下仍能「伏击」纯速度型对手。

2. 跨资产交叉信号：5 万工具的全市场模式识别

  • 模型不只看单一资产的订单簿，而是同时处理股票、固收、外汇、商品、加密 5 万余种工具的实时数据流，从跨市场海量交叉数据中识别隐秘的微观价格模式（媒体对 400PB+ 数据储备的表述，与官网 1EB+ 存储口径方向一致、量级兼容）。
  • 本质：把「资产间领先-滞后与订单流压力传导」做成特征，用算力换预测力——这是对传统线性 / 历史统计套利范代的代际升级。

3. 风险吸收型做市：报价即库存管理

  • XTX 公开强调「风险吸收能力对降低市场影响的重要性」，即报价相对较宽、主动内部化（internalize）对手方流、持有并管理库存风险，赚取波动与价差，而非毫秒级抢单后瞬间平掉。
  • 这与其在 2025 年 4 月高波动期成交创纪录的观察一致：别人撤流动性时它加码——做市商利润函数在波动率放大时占优。

4. 双轨执行：交易所做市 + SI 双边直连

  • 欧洲股票侧：顶级 ELP 系统内部化撮合商（Systematic Internalizer）地位，2025 年 SI 成交 1,770 亿欧元（+50%）、日均 6.93 亿欧元；双边模式直接向客户收费 / 吃点差，粘性与利润率高于纯交易所流动性提供。
  • 外汇侧：长期为全球最大非银即期流动性提供商之一（2021 年起 Euromoney 第一），以零 last look / 反事前对冲的服务理念著称；2020 年进入中国银行间市场。

5. 算力与人才基础设施

  • 官网口径：1 EB+ 可用存储、13,000+ GPU 研究集群、18 国交易；芬兰超大规模数据中心建设中（对冲英国算力 / 能源约束）。第三方称其累计采购 NVIDIA GPU 超 2.5 万块 待核实。
  • 人才画像：纯数学 / 物理 / CS / ML 背景的研究员主导；AI Lab（纽约）由 UT Austin 教授 Atlas Wang 领衔，做金融时序基础模型——「研究员密度」是公司仅百余人级别即支撑日均千亿美元级成交的核心。
  • 公益即招聘漏斗：AIMO Prize / IMO 赞助 / Axiom Maths 既是慈善也是品牌与人才虹吸管道。

数学模型合理性检验

XTX 内部模型细节无公开来源，本节为基于公开叙述与经典做市理论的框架性核对，检验其叙述与可观测数字之间的自洽性，而非对内部模型本身的验证。

检验 1：盈利量级 sanity check 自洽

  • 可观测口径：年净营收 ≈ £39.3 亿 ≈ $50 亿；日均成交额官网 $1,320 亿 × 约 250 个交易日 ≈ $33 万亿。
  • 净营收 / 名义成交额 ≈ 1.5bp；若按媒体 $2,500 亿/日口径（含双边重复计数）则 ≈ 0.8bp。两条口径均落在做市行业「每名义美元赚 0.2–1bp」的正常区间，无「数字好到不可信」问题。
  • 每股逻辑再交叉：净利 £17.1 亿 / 143–250 名员工 ≈ 人均 $0.7–1.2 亿利润——极端但与「无人工交易员 + 全自动」的叙事一致（Jane Street 同口径同样极端）。

检验 2：「拼预测不拼延迟」的理论等价性 自洽

  • 经典框架（Glosten–Milgrom 1985 / Avellaneda–Stoikov 2008）下，做市商利润 = 价差收入 − 逆向选择成本 − 库存风险成本 − 等待 / 撤单成本。
  • 延迟军备竞赛压缩的是等待成本与被抢单风险；XTX 的跨资产 ML 预测压缩的是逆向选择成本（对短期价格方向更准，报价被「毒流」打中的期望损失下降）。两条技术路线在数学上均能提升利润函数，选择后者且放弃前者，与其「不做毫秒抢单、主动持仓吸收风险」的业务形态内部一致——若其真实模式是抢单型，则与公开的反对延迟竞赛立场矛盾，可观测证据（SI 双边占比上升、高波动期放量）不支持该矛盾。
  • Avellaneda–Stoikov 中最优报价随 σ（波动率）与库存偏离单调外扩：与 XTX「波动越大越赚钱、报价吸收库存」的观测行为同构。

检验 3：会计口径的合理性 自洽，但注意口径

  • Technologies 主体 289% 的期初净资产收益率与 56% 净利率，源于「IP / 服务费收入 + 轻资产负债表」的结构（营收以集团内服务费形式归集），并非交易资产的年化收益——不能解读为「交易策略年化 289%」。
  • 两家 FCA 监管交易主体 2025 年利润率极薄（Trading Ltd 净利 £2,100 万 / 营收 £8.49 亿；Markets Ltd 净利 £79 万），说明成本与可变费用随营收同步放大（利润在集团内部定价中转移至 IP 主体），这与 MIFIDPRU 披露口径相符，属常见集团结构而非异常。

检验 4：无法验证的部分（诚实清单）

  • 模型族（深度网络 vs 强化学习 vs 混合）、特征体系、库存与风控约束的具体形式：零公开来源，任何「XTX 用 XX 模型」的具体断言（含中文自媒体的演绎）均无依据。
  • 「识别跨市场隐秘微观价格模式」是叙事语言，无法证伪亦无法证实；能检验的只有其外显行为与财务结果（上文 1–3 项，均自洽）。
结论：在可观测层面，XTX 的公开叙述、执行数据与财务结果三者互相咬合，未发现数学或逻辑上的硬伤；其盈利来源（价差 − 逆向选择 − 库存风险）在经典做市理论下成立。真正不可验证的是模型内部——本栏将持续以「外显行为核验」替代「内部模型猜测」。
